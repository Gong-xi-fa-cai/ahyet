# AHYET: tap intro

The page that opens when someone taps AHYET's NFC tag: a cartoon tiger introduces him.

Live: https://gong-xi-fa-cai.github.io/ahyet/

Touch once to start the intro. After it, he reacts to hidden touches (double tap, a drawn heart, a sideways drag
turns him round, and more).

The music is "Boom Bap Old School Groove" by alex-morgan (Pixabay Content License).
